Landing-page diagrams

14 finished figures across four landing-page sections.

Hi Robert — this is the working set of diagrams for the Accord landing page. Everything here is built from one shared token set (palette, type, spacing) so the figures stay visually consistent. The Tokens page lists every colour, typeface and radius value.

The isometric figures (§02, §06) are downloadable SVG vectors — drag the file straight into Figma and edit the paths directly. The product-screen mockups (§07, §08) are full HTML pages; to bring one in as editable Figma layers, run the html.to.design plugin on that screen's own URL (each "Open full screen ↗" link below is that URL).
