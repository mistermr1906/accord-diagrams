Token reference

Every value below is from the shared diagram-tokens.css. The Bible is the source of truth — if a value here disagrees, the Bible wins.

Surface ladder

Elevation is always a value step, never a shadow. A card looks "above" the page because it is lighter, darkest → lightest.

#0a0a0c

Diagram ground.

Inner edge / frosted rim. Hairline only.

The single accent — orange

One accent at two weights, not two brand colours. Never a wireframe stroke, never a background, never behind body text. Cyan/teal is fully abandoned.

--accent

#ee5f19

Solid fill: marker dots, accent bars, primary-CTA fills, focus ring.

--accent-stroke

#f7693b

1px hairline / small text over near-black. Eyebrows, crosshair.

Grey text steps

The text ramp on near-black. Off-white top, never pure white.

--text-primary

#ededed

Big numbers, headings, the one line a figure is about.

--text-quote

#bdbdbd

Serif-italic testimonial body only.

--text-secondary

#b2b2b2

Sub-labels, body, resting list rows.

--text-tertiary

#9e9e9e

Smaller captions, field labels, axis ticks.

--text-muted

#6e7176

FIG captions, tiniest micro-labels.

--text-quaternary

#4a4a4e

De-emphasised / blocked / faded-out content.
